🎶🕺 700 Classic Disco Tracks with Spotify Data
This repository features a comprehensive dataset of 700 classic disco tracks, enriched with Spotify audio features and metadata. 
This dataset is ideal for music analysts, data scientists, DJs, playlist curators, and disco enthusiasts who want to explore the 
sonic characteristics, trends, and patterns of classic disco music.

📌 Features
📊 Dataset Overview
Track Metadata: Song title, artist, album, release year.
Spotify Audio Features:
Danceability: Measures how suitable a track is for dancing.
Energy: Intensity and activity level of the song.
Valence: Musical positivity (happy/sad feel).
Tempo (BPM): Speed of the track.
Loudness (dB): Overall volume level.
Instrumentalness: Presence of vocals.
Acousticness: Whether the track is acoustic.
Liveness: Likelihood of a live performance recording.
Popularity Score: Based on Spotify streaming metrics.
Genre & Subgenre Classification: Funk, Soul, Italo Disco, Boogie, etc.
